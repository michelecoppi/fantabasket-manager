# Fantabasket Manager

Gestionale per la lega di fantabasket NBA (formato Dunkest, 8 squadre, contratti pluriennali e salary cap).

- **Admin**: modifica rose, contratti, tagli, scambi, pick del draft, budget.
- **Utenti normali**: sola lettura (rose, spazio salariale, pick, storico).

Stato: sito online con sola lettura per tutti e pannello `/admin` (firma, contratti, tagli, scambi, pick, quote). Cosa è fatto e cosa manca: [PLAN.md](PLAN.md).
